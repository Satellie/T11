# Модели JamSpell

Сюда необходимо вручную положить файлы моделей:
- ru.bin — русская модель
- en.bin — английская модель

## Где скачать

Официальный репозиторий JamSpell: https://github.com/bakwc/JamSpell

Скачайте предкомпилированные модели или скомпилируйте самостоятельно по инструкции в README.

## Установка

1. Скачайте `ru.bin` и `en.bin`
2. Положите файлы в эту папку (`models/`)
3. Запустите WSL2 сервис (см. `wsl_service/README.md`)
4. Перезапустите t10
