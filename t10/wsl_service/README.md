# WSL2 сервис для JamSpell

## Назначение

JamSpell работает как отдельный HTTP-сервис внутри WSL2 (Ubuntu), слушает `127.0.0.1:8080`.
Основное Windows-приложение общается с ним через localhost.

## Быстрый старт

```bash
# 1. Запустить скрипт сборки и сервиса
./build.sh

# 2. Проверить, что сервис доступен
curl http://127.0.0.1:8080/health
```

## Архитектура

```
┌─────────────────────┐     HTTP      ┌──────────────────┐
│  Windows t10.exe    │ ────────────> │  WSL2 JamSpell   │
│  (Python app)       │ <──────────── │  (port 8080)     │
└─────────────────────┘               └──────────────────┘
```

## Troubleshooting

- Если порт 8080 занят, измените в `corrector_jamspell.py` и `build.sh`
- WSL2 должен быть установлен: `wsl --install`
- Проверьте доступность: `curl http://127.0.0.1:8080`
